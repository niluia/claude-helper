# Lit-review skills

Three Claude skills for structuring research with Claude Code,
shared from a colleague's workshop. See the PDF for a full walkthrough.

## Skills
- `project-specs.skill` — turn an intention into a plan
- `project-verifier.skill` — define precise pass/fail criteria
- `project-environment.skill` — set up Claude's workshop (CLAUDE.md, permissions, hooks)

## How to install
In Claude, go to Settings → Skills and import each `.skill` file.
