# Claude kit

Practical tips and ready-to-use files for working efficiently with Claude, made for PhD students and researchers.

| Folder | What's inside | Who made it |
|--------|--------------|-------------|
| `Project-organizer` | How to set up a Claude Project: a one-page cheat sheet and a ready-made literature-review project to test (instructions + context files). | Nilufar |
| `Project-log` | A project diary for working with Claude: current status, a history of every step tried (accepted or discarded), to-dos, and an interactive tree of the history. Templates in English and Italian, plus a real filled-in example. | Andrea |
| `lit-review-skills` | Three Claude Code skills for structuring research projects: `project-specs`, `project-verifier`, `project-environment`. Includes a workshop presentation PDF. | Federico |

More folders with other tips will be added here.
