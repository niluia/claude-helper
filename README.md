# Claude kit

Practical tips and ready-to-use files for working efficiently with Claude, made for PhD students and researchers.

| Folder | What's inside |
|---|---|
| [Project-organizer](Project-organizer/) | How to set up a Claude Project: a one-page cheat sheet and a ready-made literature-review project to test (instructions + context files). |
| [Project-log](Project-log/) | A project diary for working with Claude: current status, a history of every step tried (accepted or discarded), to-dos, and an interactive tree of the history. Templates in English and Italian, plus a real filled-in example. |
| [project-skills](project-skills/) | Three Claude skills that guide you through preparing a project: **project-specs** (define goal and tasks before coding), **project-verifier** (define how Claude checks its work) and **project-environment** (set up CLAUDE.md, permissions, connectors, subagents, hooks). |

More folders with other tips will be added here.
