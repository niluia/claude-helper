# History

Detailed chronology of what has been done, tried, accepted or discarded. Each section matches a branch of the tree in
`history_tree.html` (same id). The current state is in `STATUS.md`, the things still to do in `notes.md`.

Legend: **[accepted]** joins the main branch; **[discarded]** tried or evaluated and dropped; **[superseded]** used for a
while and then replaced; **[running]** in progress (with who is running it); **[pending]** decided but not done yet.
Only the project leader marks a step as accepted.
